# Upstream issues found while building the benchmarks

- `diffsol_adjoint_scale.py`: pydiffsol 0.6.2 continuous adjoint fails on Robertson unless dgdu/tolerances fall in a narrow band. Rust diffsol main @ 40d3848 passes the same benchmark cases.
- pydiffsol 0.6.2 segfaults constructing `ds.Ode(code, matrix_type=ds.faer_sparse, linear_solver=ds.klu)` for the 90-state stacked Robertson (`common.robertson_diffsl(30, "params")`). Benchmarks use `ds.lu` (faer sparse LU) instead.
- Julia (OrdinaryDiffEqBDF 2.4.14, SciMLSensitivity 7.119.14, Zygote 0.7.15, Enzyme 0.13.216), FBDF on stacked Robertson:
  - `ForwardSensitivity()` fails: "First call to automatic differentiation for the Jacobian failed" (Float64(::Dual) in the augmented system), with auto or manual jac. `ForwardDiffSensitivity()` is used instead.
  - `GaussAdjoint` (EnzymeVJP with runtime activity, or ReverseDiffVJP) and `QuadratureAdjoint(ReverseDiffVJP)` return wrong p-gradients (e.g. [-17830, 44, 17801] vs [15.79, 8.14, -9.21]); u0-gradients are right. `InterpolatingAdjoint(ReverseDiffVJP(true))` is right and is used.
  - `GaussAdjoint(autojacvec=EnzymeVJP())` without runtime activity: `EnzymeRuntimeActivityError`.
  - No reverse-mode-through-the-solver option works with FBDF: `ReverseDiffAdjoint` (TypeError setting `LU{TrackedReal}` cache), `EnzymeAdjoint` (NonConstantKeywordArgException, also with `remake`), `TrackerAdjoint`, `ZygoteAdjoint`. Julia reverse-AD cells are N/A.
  - A user `jac` needs `ODEFunction{true, SciMLBase.FullSpecialize}`, otherwise "No matching function wrapper was found!".
  - With a sparse `jac_prototype` + `KLUFactorization` and an AD Jacobian (Brusselator; Robertson auto-jac at nbatch >= 20): `ForwardDiffSensitivity` fails ("First call to automatic differentiation for the Jacobian failed"), so Julia has no forward gradient here.
  - Sundials 6.7.3 `CVODE_BDF(linear_solver=:KLU)` needs a user `jac` ("No Jacobian constructor available for SUNMatrix type"; without one the solve silently returns only t0), so julia/brusselator.jl supplies a coloured sparse ForwardDiff jac. Gradients still fail: `ForwardSensitivity` -> `FieldError: type ODEForwardSensitivityFunction has no field initialization_data`; `InterpolatingAdjoint(checkpointing=true)` and `BacksolveAdjoint` -> "initialize_dae!: BrownFullBasicInit ... not implemented for the integrator" (also with `initializealg=NoInit()`). Julia+Sundials is benchmarked for solve only.
- pydiffsol 0.6.2 DFN adjoint (`solve_adjoint_bkwd`) fails immediately: "Step size is too small at time = 2500". Forward sensitivities match the reference to 2e-8.
- pydiffsol 0.6.2 Brusselator with `faer_sparse` + `lu` is slow: N=16 solve 0.27 s, N=32 solve 16 s (60x for 4x states).
- Julia DFN gradients: every option fails. `ForwardDiffSensitivity` fails on the sparse KLU Jacobian (Dual into Float64). Under Zygote, `InterpolatingAdjoint` with `ReverseDiffVJP(true)` timed out (>30 min), while `ReverseDiffVJP(false)`, `ZygoteVJP` and `EnzymeVJP` all fail in the forward solve's DAE initialisation (`BrownFullBasicInit` via NonlinearSolveBase): "MethodError: no method matching zero(::Type{Any})". The Julia DFN is solve-only.
